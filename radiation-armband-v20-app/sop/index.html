快速流程總覽（先看這 12 步）

  1. 匯入當月名單
  2. 確認名單顯示與欄位自動對應
  3. 選擇單月份 / 雙月份
  4. 切換發放模式
  5. 掃描本月臂章並按處理掃描
  6. 查看掃描結果與下方掃描紀錄
  7. 核對姓名、工號、部門後依部門裝袋
  8. 條碼不在名單內時，回上方名單補條碼、補備註、重刷一次
  9. 帶部門袋到櫃子交換上月臂章
  10. 切換繳回模式，掃描上月臂章並查看掃描紀錄
  11. 核對檢點數量與上月群組結果
  12. 匯出完整結果，更新本月名單

步驟 1：匯入當月名單

操作卡

操作位置：上方「匯入原始名單」區。
要做什麼：載入當月 Excel 名單。
成功標準：名單預覽區有出現人員資料。
常見錯誤：名單未載入就開始掃描。
現場提醒：先確認預覽，再進入掃描流程。

步驟 2：確認名單顯示與欄位自動對應

操作卡

操作位置：名單預覽區 + 欄位對應區。
要做什麼：匯入名單後先看名單預覽是否正常顯示。系統通常會依欄位關鍵字自動對應；只有顯示異常、掃描找不到、統計怪怪時才檢查欄位。
成功標準：名單預覽正常，單位/課別/工號/姓名無跑版，且本期領取、上期繳回、單月份條碼、雙月份條碼有被正確抓到。
常見錯誤：以為每次都要手動下拉，反而把自動對應好的欄位改錯。
現場提醒：正常情況先相信系統自動抓欄位；有異常時再檢查對應欄位。

步驟 3：選擇本月單月 / 雙月

操作卡

操作位置：掃描區「本期發放臂章種類」。
要做什麼：本月發放單月份臂章就選單月份；雙月份就選雙月份。
成功標準：當前種類與實際發放批次一致。
常見錯誤：選錯導致掃描找不到人或寫錯資料。
現場提醒：每次開始新批次先確認這個選項。

步驟 4：切換發放模式

操作卡

操作位置：掃描區「掃描模式」。
要做什麼：發放本月臂章時，模式要選「發放」。
成功標準：模式已停在發放，再開始掃碼。
常見錯誤：用繳回模式掃本月臂章。
現場提醒：先選單/雙月，再選發放模式。

步驟 5：掃描後執行處理掃描

操作卡

操作位置：條碼輸入框 +「處理掃描」按鈕。
要做什麼：掃入條碼後，按「處理掃描」或按 Enter 觸發處理。
成功標準：畫面出現處理結果訊息。
常見錯誤：掃完直接入袋，未讓系統處理。
現場提醒：嗶一聲只代表讀到條碼；有出現結果才算系統處理完成。

步驟 6：查看掃描結果與掃描紀錄

操作卡

操作位置：掃描結果提示 + 下方「4. 掃描紀錄」最新一筆。
要做什麼：看上方是否顯示處理成功，再看下方掃描紀錄是否新增一筆，並確認最新一筆的姓名、工號、部門、結果是否正確。
成功標準：掃描紀錄新增一筆，結果欄顯示已記錄/成功，且姓名、工號、部門與實體臂章一致。
常見錯誤：只看上方提示，不看下方掃描紀錄；或結果異常仍直接入袋。
現場提醒：不要只看上方提示，也要看下方掃描紀錄。掃描紀錄才是後續追蹤依據。

步驟 7：核對後依部門裝袋

操作卡

操作位置：現場分袋作業區。
要做什麼：核對臂章姓名與畫面資料，一致後放入對應部門袋。
成功標準：同部門臂章集中、異常件分離。
常見錯誤：未核對姓名就先入袋。
現場提醒：姓名或部門不一致，先放異常區。

步驟 8：條碼不在名單內時（補碼、補備註、重刷）

操作卡

操作位置：網頁上方「名單預覽」表格中的該人員資料列，不是在下方掃描區。
要做什麼：
  1. 掃描顯示不在名單內時，先不要入袋。
  2. 回到上方名單預覽區。
  3. 找到該人員。
  4. 點該列的單月份條碼或雙月份條碼欄。
  5. 掃入條碼。
  6. 備註欄填「本月新增」。
  7. 補條碼與補備註是在上方名單預覽區完成；補完後才回下方掃描區重刷。
  8. 回下方掃描區重刷同一條碼。
  9. 確認掃描紀錄新增成功後，才可入袋。
成功標準：補碼後重刷成功，掃描紀錄新增最新一筆。
常見錯誤：只補條碼不補備註；或補完後未重刷。
現場提醒：本月新增不是只補條碼。一定要補條碼、補備註、重刷一次。

步驟 9：帶部門袋到櫃子交換上月臂章

操作卡

操作位置：櫃位交換區。
要做什麼：先取上月臂章，再放本月臂章，最後把上月臂章裝回袋子。
成功標準：袋子標籤、櫃位、部門三者一致。
常見錯誤：全部混在一起交換，造成對錯位。
現場提醒：數量不符先記錄，不要硬湊數。

步驟 10：切換繳回模式並掃描上月臂章

操作卡

操作位置：掃描模式 + 條碼輸入框 + 掃描紀錄。
要做什麼：
  1. 模式切成繳回。
  2. 掃上月臂章條碼。
  3. 按處理掃描或 Enter。
  4. 查看結果與掃描紀錄是否新增。
  5. 確認繳回欄有更新。
成功標準：繳回掃描結果正確、紀錄新增成功。
常見錯誤：用發放模式掃上月臂章。
現場提醒：繳回流程同樣要看掃描紀錄，不可只看嗶聲。

步驟 11：核對檢點數量

操作卡

操作位置：名單狀態總覽 + 單位進度看板。
要做什麼：核對發放總數、繳回總數、完成更換、應發放、應繳回。
成功標準：數量與現場盤點一致，未完成單位已清楚列出。
常見錯誤：只看總數，不看各單位未完成名單。
現場提醒：上月發放多少，本月原則上就應繳回多少；要比對群組上月結果。

步驟 12：匯出完整結果並更新本月名單

操作卡

操作位置：匯出按鈕、匯出 Excel、本月名單。
要做什麼：
  1. 匯出完整結果。
  2. 打開匯出檔，確認有：更新後名單、單位統計看板、掃描紀錄。
  3. 複製「當月領取欄」到「雙月份條碼」區間。
  4. 貼到本月名單對應欄位。
成功標準：欄位貼正確、列數與順序一致。
常見錯誤：排序不同仍直接整段貼上。
現場提醒：貼之前確認人員排序一致；排序不同不能整段直接貼，需先對齊工號或姓名。

附錄 A：常見異常快速處理

異常先做什麼下一步
條碼不在名單內先不要入袋補條碼、補備註、重刷
結果顯示重複確認是否已掃過避免重複入袋
姓名/工號不一致放異常區人工核對後再處理
櫃位交換數量不符先記錄異常回報追查，不硬湊

  • [ ] 已確認本月單/雙月與發放模式

作業中

  • [ ] 每筆都按處理掃描 / Enter
  • [ ] 每筆都看掃描結果與掃描紀錄
  • [ ] 本月新增已做補碼、補備註、重刷

收尾

  • [ ] 已核對發放/繳回/完成更換/應發/應繳
  • [ ] 已比對上月群組結果
  • [ ] 已匯出並更新本月名單

附錄 C：5 分鐘快速版

  1. 匯入名單 → 確認名單顯示正常 → 選單雙月 → 選發放模式。
  2. 掃條碼後按處理掃描，確認結果與紀錄。
  3. 核對姓名/工號/部門後入袋。
  4. 不在名單內：補碼、補備註、重刷。
  5. 做櫃位交換，切繳回模式掃上月臂章。
  6. 核對數量後匯出，更新本月名單。
